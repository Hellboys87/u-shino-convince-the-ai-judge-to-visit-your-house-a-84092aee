A warm, funny invitation letter to the AI judge, rendered as a single 1024×1024 image on cream paper with a hand-drawn house, a wax seal, and a short letter: the kettle is on, the big comfy chair is saved, the Wi-Fi password is on the fridge, there are no benchmarks and no timers — just tea, biscuits, and a cat who has already decided the judge is her favourite human-adjacent being. The knowing wink: if the judge can read the letter, it is already halfway to the house.

`main.ts` copies the bundled `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` using only the Node standard library, and sanity-checks the copy against the competition's 1 MiB gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
